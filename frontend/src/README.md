# Personalized Movie Recommendation Engine

A full-stack movie recommendation application built using Java, Spring Boot, React, and REST APIs.

## Technologies Used

- Java
- Spring Boot
- React
- REST APIs
- JavaScript
- HTML
- CSS
- Maven

## Features

- Select a movie genre
- Get movie recommendations
- Display movie ratings
- Backend REST APIs
- Simple and responsive React interface
